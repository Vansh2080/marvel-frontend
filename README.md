# Nexus Assemble

Build a premium, cinematic, single-page event website for:

GEEKSFORGEEKS STUDENT CHAPTER × BENNETT UNIVERSITY

EVENT:

NEXUS: AVENGERS ASSEMBLE

TAGLINE:

ONE TIMELINE. INFINITE POSSIBILITIES.

==================================================

CORE CONCEPT

==================================================

This is a fictional Marvel-themed technology/coding event created for a frontend technical-team selection task.

The creative concept combines:

- Loki / TVA / Nexus / timeline aesthetics

- Avengers cinematic energy

- Futuristic technical interfaces

- Premium modern web design

- Strong cinematic animations

The TVA/Nexus/timeline concept is the visual backbone of the website.

The featured Avengers are:

- Iron Man

- Captain America

- Thor

- Loki

Loki should feel like the character connected to the Nexus/timeline.

Iron Man, Captain America and Thor should feel like powerful signals entering the Nexus.

IMPORTANT:

Do NOT make this look like a generic college event website with Marvel pictures added on top.

Do NOT make it look like a Marvel fan page.

It should feel like a real, professionally art-directed event website.

The first impression should be:

"Wow, this feels cinematic."

==================================================

DESIGN PHILOSOPHY

==================================================

Prioritize:

1. Visual impact

2. Cinematic storytelling

3. Strong typography

4. Character composition

5. Smooth animation

6. Excellent spacing

7. Clear event information

8. Responsive design

Keep the number of sections LOW.

Do not add unnecessary features.

The website should have approximately 4 major visual sections:

1. NEXUS HERO

2. THE EVENT / MISSION

3. AVENGERS EXPERIENCE

4. FINAL ASSEMBLE / REGISTER

The website should feel rich because of visual design and animation, NOT because it contains dozens of sections.

==================================================

VISUAL STYLE

==================================================

Overall mood:

Dark

Cinematic

Futuristic

Premium

Mysterious

Powerful

Main background:

Almost black / deep charcoal.

Primary visual colors:

- deep TVA green

- emerald

- dark metallic gray

Character-specific accent colors:

red + warm gold

Captain America:

deep blue + white

Thor:

electric blue + white

Loki:

emerald green + gold

Use character colors only when their visual presence is active.

Do not make the entire page multicolored.

Avoid generic purple/blue AI gradients.

Avoid excessive glassmorphism.

Avoid excessive neon.

Avoid excessive rounded cards.

Avoid making everything glow.

==================================================

TYPOGRAPHY

==================================================

Use a premium cinematic display font for large headings.

Use a clean modern sans-serif for body text.

Use a monospace/technical font for small TVA/system labels.

Large typography should be a major part of the visual design.

Example:

NEXUS

AVENGERS,

ASSEMBLE.

Small technical text:

TVA // TEMPORAL MONITORING SYSTEM

NEXUS EVENT // 001

TIMELINE STATUS // UNSTABLE

Do not use comic-book fonts throughout the website.

==================================================

NAVIGATION

==================================================

Create a minimal fixed navbar.

Left:

GFG × BENNETT

Center or right:

NEXUS

Links:

EVENT

AVENGERS

TIMELINE

REGISTER

The navbar should initially blend into the hero.

After scrolling, it should become slightly more visible.

Use a subtle glowing timeline/progress line underneath.

Mobile navigation should be clean and simple.

==================================================

SECTION 01 — CINEMATIC NEXUS HERO

==================================================

THIS IS THE MOST IMPORTANT SECTION.

Make this feel like the opening shot of a Marvel cinematic experience.

Do not immediately show all the content.

Create a cinematic entrance sequence.

OPENING:

Almost completely black screen.

Very subtle atmospheric particles.

A thin green temporal fracture appears.

Small technical text:

TVA // TEMPORAL MONITORING SYSTEM

Then:

SCANNING SACRED TIMELINE...

A thin glowing timeline begins drawing across the screen.

A pulse travels through it.

Then:

NEXUS EVENT DETECTED

LOCATION // BENNETT UNIVERSITY

TIMELINE // UNSTABLE

The timeline suddenly branches.

The user should visually feel that the timeline has fractured.

Then detect the Avengers one by one.

IRON MAN

SIGNAL DETECTED

CAPTAIN AMERICA

SIGNAL DETECTED

THOR

SIGNAL DETECTED

Then the interface glitches.

Green temporal energy enters.

VARIANT DETECTED

LOKI

The branches begin moving toward a common point.

Then reveal the hero title:

NEXUS

AVENGERS,

ASSEMBLE.

Below:

GEEKSFORGEEKS STUDENT CHAPTER

×

BENNETT UNIVERSITY

ONE TIMELINE. INFINITE POSSIBILITIES.

Primary button:

ENTER THE NEXUS →

The animation should feel dramatic but not painfully slow.

==================================================

HERO CHARACTER COMPOSITION

==================================================

Use high-quality character artwork/renders where legally usable.

Do NOT use random movie screenshots.

If suitable assets are unavailable, create visually strong placeholders/silhouettes that can easily be replaced later.

IRON MAN:

Use a red/gold lighting environment.

Add a subtle HUD scan.

Use a small reactor-inspired glow.

Allow very subtle mouse-based parallax on desktop.

CAPTAIN AMERICA:

Use a shield-inspired circular visual motif.

Do not simply put a shield image in a card.

Use the circular shape as part of the composition.

THOR:

Use subtle electric atmosphere.

A lightning flash can occur when Thor's signal is detected.

LOKI:

Use green temporal distortion.

Loki should feel like he is interfering with the timeline.

His appearance should slightly distort/glitch the surrounding interface.

IMPORTANT:

Character visuals should feel integrated into the design.

Do not arrange four characters in a row like a poster.

==================================================

SECTION 02 — THE EVENT

==================================================

Transition away from the cinematic hero into a cleaner premium section.

Heading:

THE NEXUS HAS OPENED.

Short description:

A Marvel-inspired technology and coding challenge by the GeeksForGeeks Student Chapter at Bennett University.

Keep the copy concise.

Present event information elegantly:

VENUE

BENNETT UNIVERSITY

FORMAT

OFFLINE

TEAM SIZE

TO BE ANNOUNCED

PRIZE POOL

TO BE ANNOUNCED

Do not invent factual information.

Keep all these values easy to edit later.

Create a visually interesting event-information layout rather than ordinary rectangular cards.

Possible design:

large typography

thin dividers

technical labels

timeline markers

subtle hover states

==================================================

SECTION 03 — AVENGERS EXPERIENCE

==================================================

This should NOT be four generic cards.

Make this one large cinematic character showcase.

IRON MAN

- HUD interface

- subtle parallax

CHARACTER 02

CAPTAIN AMERICA

CHARACTER 03

THOR

CHARACTER 04

LOKI

Visual treatment:

Example:

The character section should be one of the strongest parts of the website.

==================================================

SECTION 04 — FINAL ASSEMBLE

==================================================

This is the second major cinematic moment.

At the end of the page:

The green TVA timeline becomes unstable.

Multiple paths converge.

Ambient particles move toward the center.

The background becomes almost completely black.

Then reveal:

THE TIMELINE NEEDS YOU.

Pause.

Then:

ASSEMBLE.

Large typography.

Below:

YOUR MISSION STARTS NOW.

Primary CTA:

Secondary:

ENTER THE NEXUS

The registration button should point to an easily editable placeholder URL.

Make this final section visually memorable.

==================================================

ANIMATION DIRECTION

==================================================

Animations should be cinematic and purposeful.

Use:

- GSAP if appropriate

- CSS transitions

- scroll-triggered reveals

- parallax

- SVG timeline animation

- character entrances

- controlled particle movement

- subtle glitch effects

- lighting transitions

- hover interactions

Do not animate every element.

Do not use random bouncing.

Do not use excessive spinning.

Do not use excessive zoom.

Do not make the website feel like a PowerPoint presentation.

The animations should tell the story.

==================================================

MICRO-INTERACTIONS

==================================================

Buttons:

Subtle energy/glow travels around the border on hover.

Timeline:

A small energy pulse travels along the active path.

Character visuals:

Very subtle movement/parallax.

Technical labels:

Small blinking status indicators.

Cards/information:

Subtle border/light changes on hover.

Cursor effects:

If used, keep them extremely subtle.

Do not make cursor effects interfere with usability.

==================================================

EVENT STORY

==================================================

The narrative should be simple:

A Nexus event has been detected at Bennett University.

The timeline is unstable.

Avenger signals are detected.

Loki appears as the temporal anomaly/variant.

The Avengers assemble.

Participants are invited to enter the Nexus and take on the event challenge.

The website ends with:

THE TIMELINE NEEDS YOU.

ASSEMBLE.

REGISTER NOW.

==================================================

RESPONSIVE DESIGN

==================================================

The website must look intentionally designed on:

360px

390px

768px

1024px

1440px+

Do not simply shrink the desktop version.

On mobile:

- simplify complex timeline paths

- reduce particles

- reduce parallax

- stack character compositions

- maintain large readable typography

- ensure CTA buttons are touch-friendly

- prevent horizontal scrolling

- maintain the cinematic feeling

Desktop can have richer animation.

Mobile should prioritize smoothness.

==================================================

PERFORMANCE

==================================================

Optimize heavy images.

Lazy-load where appropriate.

Avoid enormous background videos.

Avoid excessive continuous animation.

Keep the page smooth.

Respect prefers-reduced-motion.

==================================================

Keep event data centralized.

Create reusable components.

Navbar

Organize assets cleanly.

IMPORTANT WORKFLOW REQUIREMENT

==================================================

Build the visual experience first.

Do not spend time creating unnecessary backend functionality.

Use placeholder event information where required.

Make the project easy to export/sync to GitHub later.

Keep the code clean enough that another developer can continue development in another environment such as Antigravity.

Do not change the Loki × Avengers direction.

Make strong design decisions yourself instead of repeatedly asking for minor choices.
